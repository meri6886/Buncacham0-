# Bún Cá Chấm 0? — Static Site

Deploy Vercel — QUAN TRỌNG:
Để domain KHÔNG đổi tên (giữ nguyên buncacham0.vercel.app),
hãy REDEPLOY vào đúng project "buncacham0" đã có sẵn trên Vercel
(Deployments → nút ⋯ → Redeploy / Upload lại vào project cũ),
KHÔNG tạo project mới mỗi lần upload.
Nếu tạo project mới, Vercel sẽ tự đặt tên domain theo tên file/thư
mục zip bạn upload (đây là lý do trước đó bạn bị domain dạng
"...-final-2.vercel.app").
